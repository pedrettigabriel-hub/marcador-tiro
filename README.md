# 🎯 Marcador de Tempo de Tiro

Ferramenta open source e gratuita para a comunidade de tiro esportivo.
Aplicação 100% em HTML/JS que roda direto no navegador — nenhum vídeo é enviado para servidores.

## Como usar
1. Acesse o link: https://pedrettigabriel-hub.github.io/marcador-tiro/
2. Carregue seu vídeo.
3. Ajuste o FPS (30, 60, 120) conforme a gravação.
4. Marque START e CHEGADA frame a frame.
5. O tempo aparece na tela.
